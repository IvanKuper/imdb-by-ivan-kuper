# TV Show Search

Search any TV show and see its poster, rating, genres, network, creators, main cast and similar shows.

**Live:** https://imdb-by-ivan-kuper.netlify.app

## How it works
- Data comes from the free [TVmaze API](https://www.tvmaze.com/api) (no API key needed).
- Plain HTML, CSS and JavaScript (`fetch`, no libraries).
- Text from the API is written with `textContent`, never as HTML.

## Run locally
Open `index.html` in a browser.
